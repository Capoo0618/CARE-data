# 擴充一般健康衛教來源

依使用者 2026-10-09 指示，將國健署主題衛教、疾管署疾病介紹、ECDC 自有疾病衛教及厚生勞動省指定預防欄目接入既有 RAG。PMDA 查得禁止自動巡迴下載，保持停用，待機構提供允許的取得方式；不繞過、不擷取藥廠文件。

沿用文章 dict → chunk → Gemini embedding → MongoDB／pgvector 的契約。只對新增一般衛教來源採 URL 識別、缺修改日期時正文雜湊；每個 chunk 保存授權、署名、語言與適用地區，不改既有來源切法、不全庫重算。

本次已獲授權分批正式入庫，允許向量 API 用量；不合併或永久部署排程。入庫使用指定來源入口，不執行完整 job() 的媒體、政府查核標記或全庫對帳刪除。來源禁令、授權變更、網路封鎖均停止該來源。

下游需要在引用／分享顯示來源、授權連結及 CARE 加工聲明，並保留外國適用地區；本 change 不擅自修改另一 repository。正文與向量維度仍為既有契約，無 schema 遷移。
