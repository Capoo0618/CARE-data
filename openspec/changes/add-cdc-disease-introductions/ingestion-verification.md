# 疾管署疾病介紹：正式入庫驗證（2026-10-08）

## 執行範圍

程式開發與單元測試完成後，依使用者指示先匯入登革熱一篇，再接續擴充完整的
「疾管署疾病介紹」來源。本紀錄是此次執行的實際結果，不是預估量或其他來源的歷史篇數。

執行於既有 `care-vm` 的 K3s `care-dev` 環境，使用原 ETL 映像的 Python 與鎖定依賴，
掛載本分支 `da90edd` 的爬蟲、主流程、共用清洗與向量寫入程式。連線設定由既有
`care-backend-secret` 注入，未下載 Secret 值至本機或寫入版控。

本次只呼叫 `get_cdc_articles()` 與 `upload_to_mongodb()`，沒有執行其他來源、媒體
推播、查核補標籤或全庫對帳。已存在的登革熱依現有增量規則跳過。

## RAG 檢索驗證

使用正式後端相同的 Gemini 查詢 embedding、pgvector、BM25、HybridRetriever 與
40 個候選設定，直接檢索而不發送 LINE 訊息或建立使用者對話。五個問句的第 1 名
候選均命中各自對應的疾管署介紹，不只檢查是否命中任意疾管署文件。

本次是一次性增量入庫，沒有合併 PR 或修改既有部署／CronJob。96 篇資料已可被現有
RAG 使用；每日自動抓取新介紹與改版，仍待 PR #10 合併並部署新 ETL 映像後生效。
臨時匯入 Job 與 ConfigMap 已在驗證後清理，正式資料保留。

詳細 JSON 證據在本機忽略版控的 `backups/cdc-expansion-2026-10-08.json`，包含文章
清單、切片數與查詢命中排名，不含金鑰。初次單篇驗證另存於
`backups/cdc-single-ingestion-2026-10-08.json`。

2026-10-09 擴充官方衛教來源時，已為本來源所有 524 個切片補齊 7 個授權／來源
